# AGENTS.md — Development Guidelines for Revio

## Technology Mandates
- **Languages**: JavaScript (`.js`), JSX (`.jsx`), CSS.
- **NO TypeScript**: No `.ts` or `.tsx` files allowed. No `tsconfig.json`. No TypeScript compiler.
- **Frontend**: React 19, Vite 8, React Router, Tailwind CSS v4.
- **Backend**: Node.js, Express.js.

## Design System Integrity
- **Brand Mark**: `RevioMark` (SVG reduction mark) and `RevioWordmark`.
- **Palette**: Dark graphite canvas (`#111110`), warm surface (`#191918`), Vermillion Signal accent (`#FF7442` / `oklch(0.685 0.175 42)`).
- **Typography**: `Instrument Serif` (`text-editorial`), `Geist` (`font-sans`), `JetBrains Mono` (`text-meta`, `text-code`).
- **Restrained Radii**: 3px sm, 4px md, 6px lg, 8px xl.
